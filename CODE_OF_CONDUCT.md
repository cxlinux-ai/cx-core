# Code of Conduct

CX Linux adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct.

## Our standard

We want CX to be a welcoming project for everyone, whatever their experience level, background, or identity. In issues, pull requests, discussions, and anywhere else you represent the project:

- Be respectful and assume good intent.
- Give and take constructive feedback gracefully.
- Focus on what's best for the project and its users.
- Don't harass, insult, or demean anyone, and don't publish anyone's private information.

## Scope

This applies in all project spaces, and in public spaces when someone is representing the project.

## Reporting

Report unacceptable behavior to the maintainers at **support@cxlinux.com**. Every report is reviewed promptly and kept confidential. Maintainers will act in line with the Contributor Covenant's [enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines).
